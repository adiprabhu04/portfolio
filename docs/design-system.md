# Design System

## Visual Identity

A futuristic AI engineer workspace with premium product aesthetics.

## Tone

* intelligent
* technical
* modern
* cinematic
* minimal
* polished

## UI Principles

* restraint over excess
* motion with purpose
* layered layouts
* clean hierarchy
* immersive interactions
* readable typography

## Layout Direction

* modular workspace panels
* Bento-grid influenced structure
* layered interface depth
* adaptive responsive layout

## Motion Language

* smooth spring animations
* staggered reveals
* subtle parallax
* soft hover transitions
* cursor-reactive lighting
* premium scrolling behavior

## Typography

* modern sans-serif
* strong hierarchy
* clean spacing rhythm
* large impactful headlines
* subtle muted secondary text

## Avoid

* generic dashboards
* template-like portfolios
* overly flashy 3D
* visual clutter
* excessive particles
* laggy animations
* neon overload
